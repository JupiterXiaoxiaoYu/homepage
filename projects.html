Similarity Service in Marketplace for NFTProject Link

Algorand NFT Similarity Service In Marketplace is a pioneering initiative centered on an NFT Similarity Service within the Algorand ecosystem, specifically tailored for AlgoSeas PIRATEs API. This innovative project features dual databases for both listing and sales data, harnessing a clustering algorithm to retrieve N similar NFTs from these databases. Leveraging machine learning, the service predicts the pricing of a queried NFT based on comprehensive historical sales data. With a primary service endpoint coordinating these functionalities, the project aims to continually update and store marketplace data, facilitating the construction of a similarity service capable of returning N similar NFT data, encompassing both active listings and sales information for a single query. Users can engage the demo query, entering a query NFT's asset ID and the desired number of similar NFTs for comparative analysis, receiving a comprehensive output including predicted prices and detailed market activity for the queried NFT and its similarities.

Role: Independent Data Engineer

Technologies: Python, Machine Learning, MongoDB
